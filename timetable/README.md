# 타임테이블 (timetable)

두 사람(햄찌·꼬까)의 공부 타이머·기록·계획 앱. 단일 HTML · 라이브러리 없음 · PWA.
배포 = https://skygenie00.github.io/genie/timetable/

## 저장소 둘

| 무엇 | 어디 |
|---|---|
| 앱 코드 (이 폴더) | `skygenie00/genie` — 공개, GitHub Pages |
| 데이터 | `zzikkaplan/studyplandata` — **Private**. `settings.json` · `sessions/<사람>/YYYY-MM.json` · `todos/<사람>.json` · `plan/<사람>.json`. 앱이 각자 토큰으로 직접 읽고 씀 |

- 토큰은 앱 설정 화면에만 넣는다. 브라우저 저장소에 산다. **코드·README·커밋 어디에도 적지 않는다.**
- 공개 저장소(genie)에 데이터 JSON·PDF 를 올리지 않는다.

## 파일

- `index.html` — 앱 전부 (화면·타이머·동기화·계획 엔진).
- `sw.js` — 서비스워커. 껍데기만 캐시, GitHub API 는 캐시하지 않음. **파일을 고치면 `V` 를 올린다.**
- `manifest.webmanifest` · `icon.svg` — PWA 껍데기.

## 설계 요약 (v1)

- v1 범위: 타이머·세션·일간/주간/월간·데일리 모음(햄찌 좌·꼬까 우)·할일(어제/오늘/내일, 학습과 할일 분리, 이월)·오프라인 큐·GitHub 동기화·PWA·크롬 문서 PiP(시트+MiMi 바 통째).
- 시간 규칙: 하루는 05:00 에 시작(설정 가능). 그 전 시각은 전날로 치고 분 값에 1440 을 더해 저장.
- 세션 = `{id,d,s(과목),p(분류명),i(계획 내용),a(시작분),b(끝분),plan,cat,nt,u(수정시각),del}`. 사람별·월별 파일이라 두 사람 사이 충돌 없음. 같은 사람 두 기기는 id 기준 병합, `u` 큰 쪽 승리, 삭제는 `del:true` 표식. 옛 `k`(○×△) 필드는 폐지 — 남아 있어도 무시.
- 동기화: 저장 4초 뒤 자동 push, 90초마다 대기분 재시도, 온라인 복귀·탭 복귀 시 pull. 409/422 면 다시 받아 병합 후 재시도 1회. 상대 파일은 읽기만.
- 로컬 키: `tt.cfg`(사람·토큰) `tt.settings` `tt.f.<path>`(파일 캐시+dirty+sha) `tt.run`(진행 중 타이머) `tt.form`.
- 색: 데일리 10h 이상 분홍 · 6h 이상 하늘(설정). 주차 라벨은 현재 프로젝트의 셀법을 따른다(아래 v2 참고).

## v2 — 계획

층 이름(feedback7 용어 통일): **프로젝트 › 과목 › 분류 › 활동(구 띠) › 세부계획(구 단원)**. 코드 내부 키(bands·units·tag·catGoal…)는 옛 이름 그대로.

- `plan/<사람>.json` (스키마 v2) = `projects[]`(프로젝트: 이름·기간 d1/d2·과목·분류·활동 bands·이정표·목표치 catGoal·기준선 baselines·양보 순서 yield·보관 arch) + `cur`(현재 프로젝트) + 세부계획 DB(units · 프로젝트 넘어 재사용) + 요일별 처리량(daily) + 월간 목표(goals).
- **주차 셀법**: 기간 확정 프로젝트는 **역산** — 종료(시험)일이 든 주 = W1, 그 앞이 W2… (라벨 = 시험까지 남은 주). 기간 미정은 시작일 주 = W1 오름차순, 표시 = 현재+8주. 격자는 월요일 기준 7일. 저장값 = 화면 라벨이고, 내부 계산은 시간순 서수(pWeekNo·bO1/bO2)로 통일.
- v1(평면 bands) 파일은 로드 때 1회 `migratePlanData` 로 프로젝트 하나(『64회 1차시험』 pj1)로 감싸고 주 라벨을 환산한다(결정적·멱등). `plan.v` 가 앱이 아는 버전보다 크면 쓰기 중단+새로고침 안내.
- 오늘 학습: 활성 활동마다 그 날 quota+밀림 개수를 세부계획 DB 에서 자동으로 꺼내 어제/오늘/내일에 보여준다. 체크 = `done[bandId]=날짜`. todos 파일에는 쓰지 않는다.
- **주월계획**(구 주차계획 · feedback9) 화면: 탭 = 주차별 | **월간별** | 진행중 | 리스트 | **달성**. 보드 머리 = 프로젝트 이름▾(전환·새 프로젝트·보관함)·기간·D-day·⚙ 설정·**☑ 선택**(다중 삭제). 활동 **몸통 클릭 = 팝업 A**(세부계획 체크 리스트 · ✎ 고르기 토글 · 저장 시 주당 재제안) · **몸통 끌기 = 시작 주 이동**(길이 유지). **⋮ 끌기 = ±N주**(양방향 · 주당 재제안), **⋮ 탭 = 활동 편집**(팝업 B: 과목→분류→활동 순 · 주차 비우면 **미배치**). 과목·분류 편집은 프로젝트 만들기/설정에서만. 이정표 기능은 feedback10 에서 폐지(데이터만 보존).
- **미배치·부하·자동 생성**(feedback10): 주차 없는 활동 = 보드 위 트레이(끌어서 칸에 놓으면 1주 배치 · 밀림/부하/일간 제외). 분류 목표치에 「5회독」처럼 숫자를 넣으면 「분류명+i+단위」 활동 N개 자동 생성 질문(미배치). 주차 머리 밑 **부하 줄** = 주당 개수 × 세부계획 1개당 평균 시간(un 연결 세션 실측 · 없으면 전과목 평균 → 30분) 과목색 스택 + ⚠(주 평균 1.5배 초과). 기간·위치 변경 시 **완료 0 활동 = 마지막 원계획을 제자리 갱신 · 완료 있으면 밀림**(질문 없음 — ⟳ 수동 재확정은 유지).
- **일간 직결**(feedback10 §6): 어제·오늘·내일 칸에 그 날 몫(quota+밀림) 자동 표시 — 체크 = 세부계획 완료(done[bandId]) 직결 · 클릭 = 타이머에 붙음(세션에 un/bd 기록 → 부하 실측의 재료) · 「활동에서 가져오기」 폐지. **생활 블록**(§7): 타이머의 「생활 ▶」 즉시 시작 · 블록 클릭으로 종류(프리셋+직접 추가·미지정) · 반복 「생활 계획」 = plan.lifePlan(그리기만) · 세션 life+nt 라 Total·부하·주월계획 전부 제외 · 빗금 회색. **계획관리**: 완료 토글 없음(완료는 일간에서만) · 과목/활동 접기 · 줄 ✕ 인라인 삭제(활동 삭제 시 세부계획 2택) · 시트 왼쪽 위 **📋 계획관리** 버튼 = 팝업(PiP 포함).
- **월간별 탭**: 월 간략 달력(3개월/줄 · 주 세로 쌓임 · 날짜 줄 + 그 주에 걸친 활동 줄만). 문법 = **색 = 과목 · 진하기 = 회독수(이름 끝 「N회독」) · 선/모양 = 분류**(팔레트 8종 — 실선·파선·점선·●·▲·■·◆·★ · 프로젝트 설정의 분류 칩에서 지정 · 기본 점선 · 저장 = 프로젝트 `catMark`). 시작 주 칩 「과목 활동」 · 걸친 주 꼬리 · 끝 주 ✕「~끝」 · 현재 주 ☐ n/per·밀림. 칩 클릭 = 팝업 A(보기+체크 전용 — 편집은 주차별).
- **달성 탭**(구 월간계획 해체): 월 목표(클릭 편집) + 과목별 달성 표(월 단위 · ‹ 이번 달 ›). 세부계획 DB 카드는 **계획관리**로 이사(과목›활동›세부계획 관리와 한 페이지 · 기간 조작은 주월계획). 월간계획 메뉴의 그래프·기준선 버튼은 타임테이블 절과 대비 줄 ⟳ 가 대신한다.
- 병합: projects 는 id 로 맞추고 안의 bands·milestones 는 id·u·del 규칙, 프로젝트 나머지 필드는 u 큰 쪽, units[과목] 은 id·u·del, daily·goals·cur 는 파일 수준 `pu` 큰 쪽 통째, baselines 는 at 합집합.
- **타임테이블 = 한 페이지**(feedback8·9): 일간(무변·카드 폭 500) → 주간 → 월간 절 세로 스크롤. 상단 고정 바의 일|주|월 = 앵커 스크롤 · **절마다 독립 내비**(‹ 오늘 › + 날짜/월 고르기 — 일간·주간·월간 따로) · 절마다 접기(월간 기본 접힘 = 지연 렌더). 주간 절 = MiMi 카드 + **세부계획 주간 캘린더 → 달성 요약(진행 바 · 클릭 = 주월계획 달성 탭) → 그래프(높이 100 · 전체|8주|4주 토글)**, 월간 절 = MiMi 점 카드 + 월간 캘린더(주간과 같은 칩 · 넘치면 +N). 캘린더 「⤢ 확대」 = 90% 모달(칩 전부·체크·끌기 동일·ESC 닫기).
- **세부계획 캘린더**: 칩 = 세부계획 하나(체크 = 완료 · 밀림 = 오늘로 빨강 · 줄 긋기). 자동 분배 = 활동 주당 몫을 주 안에서 날로(⚙: 균등 / 요일 가중치 / 과목별 요일 — 프로젝트 `dist`). 칩 끌기 = 그 날 고정(📌 · 프로젝트 `pins`) · 나머지 미완료가 자동 재배치(배치는 즉석 계산 — 저장은 done·pins 뿐). 활동 기간이 바뀌면 기간 밖 고정만 자동 해제.
- **원계획(기준선)**: 활동 깔린 프로젝트 첫 열림에 v1 자동 확정 · 캘린더 위 대비 줄의 「⟳ 다시 세우기」 = 새 vN · 큰 변경(늘리기·재배치·기간/세부계획 수 변경) 뒤 1회 질문. baselines 스냅 = 활동 주차·주당·units·dist·pins(날짜 배치 재현용) · 이력 보존. 대비 줄 = 이번 주 예정/끝냄/밀림 · 칸 「예정 N」·점선 유령칸 = 원계획 자리.
- 월간(계획) = 목표(클릭 편집)·과목별 달성 표·원계획 대비 SVG 그래프·세부계획 DB 카드·「원계획 기준선 다시 고정」. 재배치는 미리보기에서 저장 = 적용. 상대 plan 밀림이 peerLine 에 합산.
- 그 뒤 피드백으로 들어간 것: 계획관리(과목›분류›활동, todos `cats`)·공통 할일(`todos/공통.json`)·개인 할일 기한·달별 색·시험 여러 개·MiMi 주간/월간 시트·데일리 모음 스냅샷(`snaps/<사람>/YYYY-MM.json`, 칸 = 시트 축소 사진 + 확대·메모).
- **기록통합 v1(records_v1 · 8/28)**: 문항층 `records/<사람>.json`(항목 키 = 날짜|앱|단원 · 재가져오기 = 덮어씀) · 시간층 `history/<사람>.json`(노션 데일리 1회 이전분 — 앱은 읽기만·pull만). 가져오기 = 설정 「📥 학습기록 가져오기」(ⓐ 학습로그 텍스트 붙여넣기 자동 인식 — 「[OX 학습로그]」·「[물리535 학습로그]」 · 미리보기 승인해야 저장 ⓑ 같은 오리진 앱 직접 읽기 — 앱 목록 상수 `REC_APPS` 한 줄 = 새 앱 · v1 = 물리535 IndexedDB · 하루 경계 새벽 4시). 표시 = 데일리 모음 확대 모달 「푼 문제」(카드 아래·메모 위 · 분은 표시만 — Total 불산입) · 어제오늘내일 한 줄 요약 · 달성 탭 「문항 기록」(주별 정답률·헷갈림 · 막대 클릭 = 단원별 표) · 공부시간 추이 그래프(주간/월간 절 · 월별 · 이전분 옅은 톤 · est 툴팁 raw). 데일리 모음: 시간층만 있는 날짜 = 썸네일 없이 빈 칸+Total(est 는 ≈) · 같은 날짜에 앱 세션 있으면 앱 실측 우선. 시간층은 그래프·월 합계 표시에만 — 밀림·부하·달성 불산입.
