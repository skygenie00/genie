문항 JSON 에는 **교재 해설 전문**이 들어 있어 이 공개 저장소에서 걷어냈습니다.

### 처음 여는 기기에서 할 일

**⚙ 데이터·동기화 → 🔑 토큰** 에 GitHub fine-grained 토큰을 한 번 넣습니다.
`zzikkaplan/studyplandata` **읽기 권한**만 있으면 됩니다.

★ **타임테이블(zzikkaTT)과 같은 칸(`tt.cfg`)을 씁니다.** 두 앱은 주소가 같아
저장소를 공유하므로, 그 기기에서 타임테이블을 쓰고 있으면 **토큰이 이미 들어 있습니다.**

⚠ **홈화면 웹앱과 브라우저는 저장소가 별개입니다** — 웹앱 쪽은 따로 넣어야 합니다.
⚠ 토큰이 없으면 오류창 없이 **「⬆ 엑셀 불러오기」 관문**이 그대로 뜹니다.


## ★ `file://` 로 열면 안 됩니다

앱이 GitHub API 를 `fetch` 합니다. 파일을 더블클릭해서 `file://` 로 열면
브라우저가 그 요청을 막습니다(CORS). 그때는 문항이 안 들어오고 관문만 뜹니다.

⇒ **반드시 `https://skygenie00.github.io/genie/minbeop/` 주소로 여세요.**

마스터 엑셀(`N:\개인\claude\OXminbub_OMR_2026111111.xlsx`)이 바뀌면 —

(문항 JSON 은 8.6MB 지만 git 이 zlib+delta 로 처리해서 커밋을 더해도 저장소가 거의 안 큽니다.)

## 앱이 문항을 얻는 세 가지 길

1. **자동** — 기기에 문항이 **없을 때만** 비공개 저장소에서 읽습니다(토큰이 있을 때).
   이미 있으면 **절대 자동으로 덮지 않습니다.** 토큰이 없으면 조용히 관문만 뜹니다.
2. **⚙ 데이터·동기화 → 🌐 서버 문항 불러오기** — 지금 것과 서버 것의 문항 수·md5·만든 때를
   나란히 보여 주고, 사람이 확인한 뒤에 갈아 끼웁니다.
3. **⬆ 엑셀 불러오기** — 예전 그대로 남아 있습니다.

★ 어느 길이든 **회독·태그·메모·형광펜은 건드리지 않습니다.** 문항만 갈립니다.

## ⚠ 주소가 바뀌면 기록이 따라오지 않습니다

브라우저는 주소(origin)마다 저장소를 따로 씁니다. 볼트에서 `file://` 로 쓰던 기록은
`github.io` 주소에서 **새로 시작**합니다. 옮기기 전에 —

1. 기존 기기에서 **⚙ → ⬇ 내보내기** 로 기록 파일(`ox_progress….json.gz`)을 뜬다
2. 새 주소에서 **⬆ 불러오기** 로 그 파일을 넣는다

⚠ 홈화면 웹앱과 브라우저도 저장소가 별개입니다(2026-08-29 실측).
